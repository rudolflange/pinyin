## Pinyin conversor

Container de docker com web app conversor de caracteres Pinyin para Zhōngwén. Usa o latest node.js. Dado o escopo, optei por todo o projeto contido no html.

### Preview

![Exemplo de Pinyin](pinyin_sshot.png)

### Instalação

```bash
docker compose up -d
```

### Acessar

Acesso pelo endereço `http://localhost:5151` no navegador.
